# 在 Windows 上的 IIS 服务器安装 SSL 证书（阿里云）

::: tip 背景

老旧服务器，怕以后阿里云删除帮助文档，固记录备用。

:::

## 操作步骤

### 步骤一：准备SSL证书

在阿里云控制台-数字证书管理服务-购买、创建、部署。

详略。

### 步骤二：配置系统与网络环境

1. 开放安全组的 443 端口。
2. 开放服务器防火墙的443端口。

详略。

### 步骤三：在MMC导入SSL证书（重点）

1. 单击左下角开始菜单，搜索并打开运行对话框，输入mmc，单击确定。

2. 在MMC控制台，添加证书管理单元。

    - 控制台的顶部菜单栏，选择。

    - 在添加或删除管理单元对话框，从左侧可用的管理单元列表中选择证书，单击添加。添加或删除管理单元界面

    ![alt text](https://cdn.jsdelivr.net/gh/jonaslgtm/fucang-imgs@latest/help-static-aliyun-01.png)

    - 在证书管理单元对话框，选择计算机账户，单击下一步。

    - 在选择计算机对话框，选择本地计算机（运行此控制台的计算机），单击完成。

    - 在添加或删除管理单元对话框，单击确定。

3. 在控制台左侧导航栏，展开，然后将光标放置在个人并单击鼠标右键，选择。打开证书导入向导

    ![alt text](https://cdn.jsdelivr.net/gh/jonaslgtm/fucang-imgs@latest/help-static-aliyun-02.png)

4. 根据对话框提示，完成证书导入向导。

    - 欢迎使用证书导入向导：单击下一步。

    - 要导入的文件对话框：单击浏览，打开PFX格式的证书文件，单击下一步。

        ![alt text](https://cdn.jsdelivr.net/gh/jonaslgtm/fucang-imgs@latest/help-static-aliyun-03.png)

    - 在打开文件时，您必须先将文件类型设置为所有文件（*），然后再选择证书文件。

    - 为私钥键入密码：打开TXT格式的私钥文件，复制文件内容，并将内容粘贴在密码文本框，单击下一步。

    - 证书存储：选中根据证书类型，自动选择证书存储，单击下一步。

    - 正在完成证书导入向导：单击完成。

    - 收到导入成功提示后，单击确定。

### 步骤四：在IIS管理器为网站绑定SSL证书（重点）

老版本：**Windows Server 2008 R2**

1. 添加网站绑定。请根据服务器操作系统的版本选择相应的操作步骤。
单击开始菜单，单击。

    - 在左侧连接区域，展开服务器，单击网站，在网站列表单击对应的网站，在右侧操作区域，单击绑定。

    ![alt text](https://cdn.jsdelivr.net/gh/jonaslgtm/fucang-imgs@latest/help-static-aliyun-04.png)

    - 在网站绑定对话框，单击添加。

    - 在添加网站绑定对话框，完成网站的相关配置，并单击确定。请根据以下两种业务场景进行选择。

    - 为单个网站配置证书：只需要为 IIS 服务器上的一个网站配置证书，或多个网站配置同一个证书。

**为单个网站配置证书**

  ![alt text](https://cdn.jsdelivr.net/gh/jonaslgtm/fucang-imgs@latest/help-static-aliyun-05.png)

- 类型：选择https。

- IP地址：选择服务器的IP地址。当网站部署在本服务器上且本服务器不存在多个IP地址的情况时，保持全部未分配即可。

- 端口：默认为443，无需修改。

**说明**

- 建议端口设置为 443。若设置为非 443 端口，则通过浏览器访问网站时，必须在网站域名后添加端口号（例如：<https://domain.com:8443）。>

- SSL证书：选择已导入的证书。

- 完成配置后，您可以在网站绑定列表查看已添加的https类型网站绑定。
